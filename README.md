# Videos horóscopo — Diario Astral

Repo **autogenerado** por el workflow `reel-generar.yml` (sin LLM: generador
determinista + HyperFrames).

- Cada ejecución borra los vídeos anteriores y deja solo los 12 del día:
  `YYYY-MM-DD-signo.mp4` (12 ficheros, nada más).
- `vendor/` es un mirror del repo privado `webAstrologia` (generador + corpus +
  plantilla + bgm). Lo sincroniza solo el cron nocturno. **No editar a mano.**
- Los MP4 nunca van a Hostinger ni al repo web.
